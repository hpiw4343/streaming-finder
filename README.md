# Streaming Finder

A simple guide from InfoWest that helps people pick streaming services and walks them through setup, step by step.

Live site is served by GitHub Pages from the main branch.

## Updating

1. Replace `index.html` with the new version.
2. Open `sw.js` and change `VERSION` (for example `sf-v1` to `sf-v2`) so phones and tablets that installed the app download the new copy.
3. Commit. GitHub Pages updates in a minute or two.
